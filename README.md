# GIS 2027: Flight Recorder

Teaching materials for a practitioner session proposed for the Global Insurance Symposium, Apr 13 to 14, 2027, Des Moines, also used at **DAMA Rocky Mountain, October 2026** to show the four gateways of AI security and data privacy.

**Read first: [User Guide (PDF)](docs/Flight-Recorder-User-Guide.pdf) | [User Guide (Word)](docs/Flight-Recorder-User-Guide.docx)**

**Live demo:** https://nathanplatteruser.github.io/gis-2027/flight-recorder/ , or open `flight-recorder/index.html` (or the GitHub Pages link in the repo sidebar). All policy data is SYNTHETIC SAMPLE DATA; see [DATA-SOURCES.md](flight-recorder/DATA-SOURCES.md).

- [`dama-2026/`](dama-2026/) DAMA Rocky Mountain, Oct 2026: four gateways labs in Python (mock mode or a local model), AGENTS.md, guardrails.yaml. Setup guide: [Word](docs/Four-Gateways-Setup-Guide.docx) | [PDF](docs/Four-Gateways-Setup-Guide.pdf). Demo overlay: add `?gateways=1` to the demo link
- [`flight-recorder/`](flight-recorder/) the demo, README with Mac and Windows steps, screenshots
- [`flight-recorder/takehomes/`](flight-recorder/takehomes/) permission-card template, pilot-to-production checklist, curveball checklist
- [`docs/`](docs/) user guide (.pdf and .docx)
- [`flight-recorder/TEST-REPORT.md`](flight-recorder/TEST-REPORT.md) browser emulation test results
- [`tests/`](tests/) the automated test scripts (`run.mjs` full walkthrough, `gateways.mjs` four gateways view)
- [`flight-recorder/docs/`](flight-recorder/docs/) run of show and walkthrough script
