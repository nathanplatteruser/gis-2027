# GIS 2027: Flight Recorder

Teaching materials for a practitioner session proposed for the Global Insurance Symposium, Apr 13 to 14, 2027, Des Moines.

**Live demo:** open `flight-recorder/index.html` (or the GitHub Pages link in the repo sidebar). All data is fictional.

- [`flight-recorder/`](flight-recorder/) the demo, README with Mac and Windows steps, screenshots
- [`flight-recorder/takehomes/`](flight-recorder/takehomes/) permission-card template, pilot-to-production checklist
- [`flight-recorder/docs/`](flight-recorder/docs/) run of show and walkthrough script
